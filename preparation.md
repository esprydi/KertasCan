kamu seorang software engineerbuatkan sebuah project website untuk scan ocr dokumen kertas ke bentuk file spreadsheet.

untuk flownya:
user upload file dokumen kertas -> sistem scan ocr -> sistem extract data -> sistem tampilkan hasil -> jika ingin masukan document ocr lagi user bisa upload lagi dan seterusnya -> jika sudah selesai user bisa download hasil ocr dalam bentuk file spreadsheet online, jadi langsung dibuatkan file spreadsheet online dan user bisa download.

untk teknologi nya bisa digunakan python dan menggunakan framework django dan menggunakan library ocr seperti pytesseract, atau bisa juga menggunakan api dari google cloud vision ai.

berikan saya juga panduan untuk project ini agar saya bisa memodifikasi nya sesuai keinginan saya.

untuk tampilannya bisa simple saja namun responsif dan mudah digunakan.

buatkan implementasi planningnya masukan ke file planning.md, buat step by stepnya yang mudah dipahami oleh seorang junior developer atau model murah sekalipun. fokus utama pada kemudahan implementasi dan pemahaman.
